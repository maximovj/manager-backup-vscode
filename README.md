# 🚀 SISTEMA DE GESTIÓN DE BACKUPS VS CODE

Este es un script shell bash una versión mejorada de script shell sh.

**Compatibilidad**
- con Linux (Ubuntu, Debian, Fedora, Arch, CentOS, Red Hat, openSUSE, etc.)
- con WSL (Windows Subsystem for Linux)
- con Git Bash (viene con Git para Windows)
- con MacOS 
    - Solo necesitas ejecutarlo con `bash manager_backup_vscode.sh`

# Como usarlo

Para empezar a usar el script de **`manager_backup_vscode.sh`**

```shell
# Dar permisos de ejecución del script
$ sudo chmod +x ./manager_backup_vscode.sh
# Ejecutar script
$ ./manager_backup_vscode.sh 
```
